# ClassBridge 화면 명세서

갱신일: 2026-10-29

- 화면 문구는 일본어로 표시한다.
- 현재 구현된 화면과 구현 예정인 기능을 구분한다.
- HTML 화면은 Thymeleaf로 표시한다.
- 입력값 검사와 접근 제한은 서버에서도 수행한다.

## 1. 홈 — 구현 완료

- 목적: 로그인 상태 확인과 주요 기능 진입
- 표시: 서비스명과 안내 문구
- 비로그인 상태: 로그인·회원가입 링크
- 로그인 상태: 로그인한 이메일과 학생 관리 진입 링크, 로그아웃 버튼
- 로그아웃 후 홈으로 이동

## 2. 로그인 — 구현 완료

- 현재 Spring Security 기본 로그인 화면을 사용한다.
- 입력: 이메일과 비밀번호
- 기본 화면의 Username 칸에 이메일을 입력한다.
- 실패하면 로그인 화면에 오류 안내를 표시한다.
- 보호된 화면에서 로그인으로 이동했다면 성공 후 원래 요청 화면으로 돌아간다.
- 로그인 실패 안내를 별도 화면으로 만들지 않는다.

## 3. 회원가입 — 구현 완료

- 입력: 이메일, 비밀번호
- 성공: 홈으로 이동
- 실패: 같은 회원가입 화면에 오류 메시지 표시
- 오류 시 이메일은 유지하고 비밀번호는 다시 입력한다.
- 중복 계정 안내를 별도 화면으로 만들지 않는다.

## 4. 학생 목록 — 구현 완료

- 표시: 학생 이름, 학습 시작일, 학습 레벨
- 학생 이름을 클릭하면 학생 상세로 이동
- 학생 등록 링크와 홈으로 돌아가는 링크 제공
- 로그인한 강사 자신의 학생만 표시
- 학생이 없으면 안내 문구 표시

## 5. 학생 등록 — 구현 완료

- 필수 입력: 학생 이름
- 선택 입력: 학습 시작일, 학습 레벨, 강사 메모
- 학습 레벨: 입문·초급·중급·고급
- 성공: 학생 목록으로 이동
- 입력 오류: 같은 화면에 오류와 입력값 표시

## 6. 학생 상세 — 기본 기능 완료, 확장 예정

### 현재 표시

- 학생 이름
- 학습 시작일
- 학습 레벨
- 강사 메모

### 현재 연결

- 학생 정보 수정
- 학생 삭제
- 해당 학생의 수업 목록
- 학생 목록으로 돌아가기

### 추가할 정보

1. 다음 예정 수업
2. 가장 최근 수업일보의 다음 확인 사항
3. 누적 학습 관찰 이력
4. 분류별 관찰 기록 조회
5. 관찰 기록이 작성된 수업일보로 이동

### 조회 규칙

- 다음 수업은 현재 이후의 SCHEDULED 수업 중 가장 가까운 일시다.
- 최근 일보는 연결된 수업 일시를 기준으로 찾는다.
- 최근 일보에 다음 확인 사항이 없으면 없다고 표시한다.
- 관찰 이력은 수업 일시의 최신순으로 표시한다.
- 분류는 전체·문법·표현·발음·회화·듣기·기타로 선택한다.
- 관찰 이력에는 수업 일시, 분류, 항목, 관찰 내용을 표시한다.
- 일보에 저장한 데이터를 조회하며 학생 상세용으로 복사 저장하지 않는다.
- 한 번의 관찰을 학생의 고정된 습관이나 능력으로 단정하지 않는다.
- 출결 횟수·관찰 항목별 횟수 통계는 이번 범위에서 제외한다.

## 7. 학생 정보 수정 — 구현 완료

- 기존 학생 정보를 입력 칸에 표시
- 수정 가능: 이름, 학습 시작일, 학습 레벨, 강사 메모
- 성공: 학생 상세로 이동
- 입력 오류: 같은 화면에 오류와 입력값 표시

## 8. 학생 삭제 — 기본 기능 완료, 보완 예정

- 학생 상세에서 확인창을 거쳐 POST 요청으로 삭제
- 성공: 학생 목록으로 이동
- 다른 강사의 학생은 삭제할 수 없음
- 연결된 수업이 있는 학생의 삭제 정책과 안내는 별도로 보완
- 현재 하위 데이터가 자동 삭제된다고 안내하지 않음

## 9. 수업 목록 — 기본 기능 완료, 일보 연결 예정

### 현재 표시

- 학생 이름
- 수업 일시
- 상태
- 상태 메모

### 현재 연결

- 수업 등록
- 수업 일시 변경
- 상태와 상태 메모 변경
- 학생 상세로 돌아가기

### 정렬

- 수업 일시의 오름차순
- 같은 일시면 ID의 오름차순

### 추가할 일보 연결

- 출석 상태이고 일보가 없으면 일보 작성 링크 표시
- 일보가 있으면 일보 보기 링크 표시
- 비출석 수업에는 작성 링크 대신 작성 조건 안내
- 링크 표시 여부와 별개로 서버에서도 작성 가능 여부 검사

별도의 수업 상세 화면은 이번 단계에서 만들지 않는다.
수업 목록에서 일보 작성·조회로 연결한다.

## 10. 수업 등록 — 구현 완료

- 표시: 학생 이름
- 필수 입력: 수업 날짜와 시간
- 분 단위 입력
- 등록 시 상태는 SCHEDULED
- 성공: 해당 학생의 수업 목록으로 이동
- 입력 오류: 같은 화면에 오류와 입력값 표시

## 11. 수업 일시 수정 — 구현 완료

- 표시: 학생 이름과 기존 수업 일시
- 필수 입력: 변경할 수업 날짜와 시간
- 성공: 해당 학생의 수업 목록으로 이동
- 입력 오류: 같은 화면에 오류와 입력값 표시

## 12. 수업 상태·상태 메모 변경 — 기본 기능 완료

- 표시: 학생 이름과 수업 일시
- 상태 선택: 예정·출석·취소·결석
- 상태 메모: 선택 입력
- 기존 상태와 메모를 미리 표시
- 메모를 지우고 저장하면 기존 메모도 제거
- 성공: 해당 학생의 수업 목록으로 이동
- 입력 오류: 같은 화면에 오류와 입력값 표시
- 상태 메모를 위한 별도 화면은 만들지 않음

### 추가할 규칙

- 일보가 있는 수업은 출석 이외의 상태로 바꾸지 못하게 한다.
- 변경을 시도하면 이유를 안내하고 DB 값은 유지한다.
- 출석 상태를 유지하면서 상태 메모를 수정하는 것은 허용한다.

## 13. 수업일보 통합 작성 — 구현 예정

### 진입

- 수업 목록에서 일보 작성 링크로 이동
- 로그인한 강사의 출석 수업에만 작성 가능
- 이미 일보가 있으면 중복 작성하지 않도록 기존 일보로 안내

### 표시

- 학생 이름
- 수업 일시
- 출석 상태

### 입력

- 수업 내용: 필수, 최대 2000자
- 다음 확인 사항: 선택, 최대 1000자
- 학습 관찰 항목: 0개 이상

관찰 항목 한 개의 입력:
- 분류: 필수
- 항목: 필수, 최대 100자
- 관찰 내용: 필수, 최대 1000자

### 관찰 분류

- 문법: GRAMMAR / 文法
- 표현: EXPRESSION / 表現
- 발음: PRONUNCIATION / 発音
- 회화: SPEAKING / 会話
- 듣기: LISTENING / 聞き取り
- 기타: OTHER / その他

### 조작

- 관찰 항목 추가
- 입력 중인 관찰 항목 제거
- 저장
- 수업 목록으로 돌아가기

### 저장

- 관찰 항목은 처음에는 0개로 시작한다.
- 필요할 때 항목을 추가한다.
- 추가한 항목은 분류·항목·내용을 모두 입력해야 한다.
- 작성하지 않을 항목은 제거한 뒤 저장한다.
- 저장 버튼 한 번으로 일보와 관찰 항목을 함께 저장한다.
- 성공하면 작성한 일보 상세로 이동한다.
- 입력 오류가 있으면 전체 저장을 취소한다.
- 오류 메시지와 입력한 일보·관찰 항목을 같은 화면에 유지한다.

## 14. 수업일보 상세 — 구현 예정

### 표시

- 학생 이름과 수업 일시
- 수업 내용
- 관찰 항목 목록
- 다음 확인 사항
- 최초 작성 시각과 마지막 수정 시각

### 연결

- 일보 수정
- 해당 학생의 수업 목록
- 학생 상세

### 빈 항목

- 관찰 기록이 없으면 등록된 관찰 기록이 없다고 표시
- 다음 확인 사항이 없으면 없다고 표시

## 15. 수업일보 통합 수정 — 구현 예정

- 기존 일보와 관찰 항목을 입력 칸에 표시
- 수업 내용과 다음 확인 사항 수정
- 관찰 항목 추가·변경·삭제
- 작성 화면과 같은 입력 규칙 적용
- 저장 버튼 한 번으로 전체 변경을 반영
- 일부 처리에 실패하면 전체 변경을 롤백
- 성공: 일보 상세로 이동
- 입력 오류: 수정 화면에 오류와 입력 내용 유지
- 최초 작성 시각은 유지하고 수정된 기록의 수정 시각을 갱신
- 다른 일보의 관찰 ID를 보내도 변경할 수 없도록 서버에서 확인

관찰 기록을 따로 작성하는 화면은 만들지 않는다.
학생 상세의 기록 수정도 해당 일보 수정 화면으로 연결한다.

## 16. 오류 및 접근 제한

### 구현 완료

- 학생이 없거나 다른 강사의 학생이면 404 안내
- 수업이 없거나 다른 강사의 수업이면 404 안내
- 로그인하지 않은 사용자는 로그인 화면으로 이동
- 입력 오류는 해당 입력 화면에서 안내

### 구현 예정

- 일보가 없거나 다른 강사의 일보이면 404 안내
- 비출석 수업의 일보 작성 시 이유와 수업 목록으로 돌아가는 링크 표시
- 중복 일보 작성 시 기존 일보로 안내
- 일보가 있는 수업의 상태 변경 제한 안내

### 공통 원칙

- 오류 안내에 다른 강사의 학생·수업 정보를 노출하지 않는다.
- 화면의 링크를 숨기는 것만으로 권한 처리를 끝내지 않는다.
- 조회 요청과 저장 요청 모두 서버에서 소유 강사를 확인한다.
- POST 요청의 CSRF 보호를 유지한다.
