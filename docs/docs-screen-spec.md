# ClassBridge 화면 명세서

## 1. 랜딩/서비스 소개 화면

- 목적: 서비스 핵심 가치와 로그인·회원가입 진입 경로 제공
- 표시: 서비스 소개, 핵심 흐름, 로그인 버튼, 회원가입 버튼
- 연결: 로그인 화면, 회원가입 화면

## 2. 로그인 화면

- 목적: 강사 계정 인증
- 입력: 이메일, 비밀번호
- 버튼: 로그인, 회원가입으로 이동
- 성공: 학생 목록 화면으로 이동
- 실패: 로그인 실패 안내 화면으로 이동

## 3. 로그인 실패 안내

- 목적: 잘못된 인증 정보 안내
- 표시: 로그인 실패 메시지
- 버튼: 로그인 화면으로 돌아가기

## 4. 회원가입 화면

- 목적: 새 강사 계정 생성
- 입력: 이메일, 비밀번호
- 버튼: 회원가입, 로그인으로 이동
- 성공: 로그인 화면 또는 학생 목록 화면으로 이동
- 실패: 중복 계정 안내 화면으로 이동

## 5. 중복 계정 안내

- 목적: 이미 등록된 이메일 안내
- 표시: 중복 계정 메시지
- 버튼: 로그인 화면으로 이동, 회원가입 화면으로 돌아가기

## 6. 학생 목록 화면

- 목적: 로그인한 강사의 학생 목록 조회
- 표시: 학생 이름, 학습 시작일, 현재 레벨
- 버튼: 학생 등록, 학생 상세 조회, 로그아웃
- 빈 상태: 등록된 학생이 없음을 표시
- 권한: 본인 소유 학생만 표시

## 7. 학생 등록 화면

- 목적: 새 학생 기준 정보 등록
- 입력: 이름, 학습 시작일, 현재 레벨, 강사용 메모
- 버튼: 저장, 취소
- 성공: 학생 상세 화면으로 이동
- 검증: 필수 정보가 없으면 저장하지 않음

## 8. 학생 상세 화면

- 목적: 학생 기본 정보와 다음 수업 준비 정보 통합 조회
- 표시:
  - 학생 기본 정보
  - 가장 가까운 예정 수업
  - 최근 수업 기록
  - 이전 수업의 다음 수업 확인사항
  - 출석·취소·결석 횟수
  - 반복 학습 관찰 항목별 횟수
- 버튼: 학생 정보 수정, 학생 삭제, 수업 등록, 수업 이력 조회
- 빈 상태: 수업 또는 관찰 기록이 없음을 표시

## 9. 학생 정보 수정 화면

- 목적: 기존 학생 정보 변경
- 입력: 이름, 학습 시작일, 현재 레벨, 강사용 메모
- 버튼: 저장, 취소
- 성공: 학생 상세 화면 갱신

## 10. 수업 등록 화면

- 목적: 학생별 단일 수업 예약
- 입력: 수업 일시
- 기본값: 수업 상태는 예정
- 버튼: 저장, 취소
- 성공: 수업 상세 화면 또는 수업 이력 목록으로 이동

## 11. 수업 이력 목록 화면

- 목적: 학생의 수업 이력을 시간순으로 조회
- 표시: 수업 일시, 수업 상태, 취소·결석 메모 요약
- 버튼: 수업 상세 조회, 수업 등록
- 정렬: 수업 일시 기준 시간순

## 12. 수업 상세 화면

- 목적: 수업 정보와 후속 작업 진입점 제공
- 표시: 수업 일시, 수업 상태, 상태 메모, 수업일보 요약
- 버튼:
  - 수업 상태 변경
  - 상태 메모 입력
  - 수업 일시 수정
  - 수업일보 작성 또는 상세 조회
- 규칙: 출석 수업에서만 수업일보 작성 버튼을 표시

## 13. 수업 상태 변경 화면

- 목적: 수업의 실제 진행 상태 변경
- 선택: 예정, 출석, 취소, 결석
- 버튼: 저장, 취소
- 후속 처리: 취소·결석 선택 시 상태 메모 입력으로 안내 가능

## 14. 상태 메모 입력 화면

- 목적: 취소 또는 결석 사유 기록
- 입력: 상태 메모
- 버튼: 저장, 취소
- 규칙: 정식 수업일보를 대신하지 않음

## 15. 수업 일시 수정 화면

- 목적: 등록된 수업 일정 변경
- 입력: 변경할 수업 일시
- 버튼: 저장, 취소
- 성공: 수업 상세와 학생별 수업 이력에 변경 사항 반영

## 16. 수업일보 작성 화면

- 목적: 출석 수업의 학습 내용 기록
- 입력:
  - 진행 내용
  - 학생 반응
  - 강사 메모
  - 다음 수업 확인사항
- 버튼: 저장, 취소, 학습 관찰 기록으로 이동
- 규칙: 출석 상태 수업에서만 접근 가능

## 17. 수업일보 상세 화면

- 목적: 저장된 수업일보 조회 및 수정
- 표시: 진행 내용, 학생 반응, 강사 메모, 다음 수업 확인사항, 학습 관찰 기록
- 버튼: 수정, 학습 관찰 기록 추가
- 연결: 학생 상세의 다음 수업 준비 정보에 다음 수업 확인사항 제공

## 18. 학습 관찰 기록 화면

- 목적: 수업 중 관찰한 학습 특징 기록
- 선택 분류: 문법, 표현, 발음, 말하기, 듣기
- 입력: 세부 관찰 항목, 보충 메모
- 버튼: 저장, 취소
- 규칙:
  - 하나 이상의 관찰 항목을 선택해야 저장 가능
  - 출석 수업에서만 작성 가능
  - 자동 평가 또는 능력 판정 문구는 표시하지 않음

## 19. 비출석 수업 안내

- 목적: 예정·취소·결석 수업에서 정식 수업일보를 작성할 수 없음을 안내
- 표시: 수업일보 작성 불가 사유
- 버튼: 수업 상세로 돌아가기
- 대안: 취소·결석 수업은 상태 메모만 기록 가능

## 공통 권한 규칙

- 비로그인 사용자는 로그인 화면으로 이동합니다.
- 로그인한 강사는 자신의 학생과 하위 데이터만 볼 수 있습니다.
- 다른 강사의 데이터는 목록, 상세 URL, API 요청에서 모두 차단합니다.
