# ClassBridge 화면 명세서

갱신일: 2026-11-17

## 공통 원칙

- 화면 문구는 일본어로 표시한다.
- 현재 구현된 기능과 향후 검토할 기능을 구분한다.
- 화면은 Thymeleaf로 생성하고 공통 CSS와 화면별 CSS를 사용한다.
- JavaScript는 입력 영역 전환, 관찰 항목 추가·제거, 홈의 부분 갱신에 사용한다.
- 입력값 검사와 접근 제한은 서버에서도 수행한다.
- 주요 화면에 홈으로 이동하는 고정 로고 헤더를 표시한다.
- 좁은 화면에서는 카드 배치를 변경하고 표에 가로 스크롤을 제공한다.

## 1. 홈 — 구현 완료

### 비로그인 상태

- 서비스 소개와 안내 문구 표시
- 로그인·회원가입 링크 제공

### 로그인 상태

- 로그인한 이메일 표시
- 학생 목록·학생 등록 링크 제공
- 수업 달력 표시
- 선택한 날짜의 수업 스케줄 표시
- 미작성 수업일보가 있을 때 해당 목록 표시
- 로그아웃 버튼 제공
- 로그아웃 후 홈으로 이동

### 처음 표시할 수업일

- 일본 시간 기준 오늘부터 조회한다.
- 예정(SCHEDULED) 수업이 있는 가장 가까운 날짜를 선택한다.
- 선택한 날짜의 모든 상태의 수업을 표시한다.
- 오늘 예정 수업이 없으면 다음 예정 수업일을 선택한다.
- 오늘 이후 예정 수업이 없으면 안내 문구를 표시한다.
- 처음 표시할 달력은 선택한 수업일이 속한 월로 설정한다.
- 표시할 수업일이 없으면 일본 시간 기준 이번 달을 표시한다.

### 수업 달력

- 일요일부터 토요일 순서로 표시한다.
- 이전 달·다음 달로 이동할 수 있다.
- 일요일은 빨간색, 토요일은 파란색으로 표시한다.
- 오늘은 테두리로 구분한다.
- 수업 목록에 표시 중인 날짜는 선택 배경으로 구분한다.
- 예정·출석·지각 수업이 하나라도 있는 날에 7px 회색 점을 표시한다.
- 같은 날짜에 수업이 여러 개 있어도 점은 하나만 표시한다.
- 결석·취소 수업만 있는 날에는 점을 표시하지 않는다.
- 점이 없는 날짜도 선택할 수 있다.
- 날짜를 선택하면 해당 날짜의 모든 상태의 수업을 조회한다.
- 수업이 없는 날짜에는 날짜와 함께 수업이 없다는 안내를 표시한다.
- 월 이동은 달력만 변경하고, 아래 수업 목록은 유지한다.
- JavaScript로 필요한 HTML 영역만 교체하며 페이지 전체를 다시 불러오지 않는다.
- 조회 중 안내와 요청 실패 안내를 제공한다.
- 새 요청이 들어오면 이전 요청을 취소하고 이전 결과가 화면을 덮어쓰지 않도록 한다.
- 요청 실패 시 기존 달력과 수업 목록을 유지한다.

### 수업 스케줄

표시 항목:

- 수업 시간
- 학생 이름
- 출결 상태
- 작업 링크

연결:

- 수업 시간 → 수업 준비 화면
- 학생 이름 → 학생 상세
- 출결·일보 입력 화면
- 일보가 있으면 일보 상세
- 출석·지각 상태이고 일보가 없으면 일보 작성
- 해당 학생의 전체 수업 목록

정렬:

- 수업 일시 오름차순
- 같은 일시면 수업 ID 오름차순

### 미작성 수업일보

- 출석·지각 상태이면서 일보가 없는 수업만 표시한다.
- 해당 수업이 없으면 영역 자체를 숨긴다.
- 미작성 건수, 수업 일시, 학생 이름, 일보 작성 링크를 표시한다.
- 오래된 수업부터 표시한다.
- 로그인한 강사의 수업만 표시한다.
- 일보를 작성한 수업은 다시 조회할 때 목록에서 제외된다.
- 현재 출결 입력 화면에서는 출석·지각 저장 시 일보를 함께 저장한다.
- 따라서 이 목록에는 기존 데이터 등에서 일보가 없는 출석·지각 수업이 표시된다.

## 2. 로그인 — 구현 완료

- 독자적으로 작성한 로그인 화면을 사용한다.
- 입력: 이메일, 비밀번호
- 인증 처리는 Spring Security가 수행한다.
- 로그인 실패 시 같은 화면에 오류 안내를 표시한다.
- 보호된 화면에서 로그인으로 이동했다면 성공 후 저장된 요청으로 돌아간다.
- 로그인 실패 안내를 별도 화면으로 만들지 않는다.
- CSS와 JavaScript 정적 파일은 로그인 없이 접근할 수 있다.

## 3. 회원가입 — 구현 완료

- 입력: 이메일, 비밀번호
- 성공: 홈으로 이동
- 실패: 같은 화면에 오류 메시지 표시
- 오류 시 이메일은 유지하고 비밀번호는 다시 입력한다.
- 이메일 중복 등록을 검사한다.
- 중복 계정 안내를 별도 화면으로 만들지 않는다.

## 4. 학생 목록 — 구현 완료

- 학생 이름, 학습 시작일, 학습 레벨 표시
- 학생 이름 클릭 시 학생 상세로 이동
- 표 아래에 학생 등록 링크와 홈으로 돌아가는 링크 제공
- 로그인한 강사 자신의 학생만 표시
- 학생이 없으면 안내 문구 표시

## 5. 학생 등록 — 구현 완료

- 필수 입력: 학생 이름
- 선택 입력: 학습 시작일, 학습 레벨, 강사 메모
- 학습 레벨: 입문·초급·중급·고급
- 성공: 학생 목록으로 이동
- 입력 오류: 같은 화면에 오류와 입력값 표시

## 6. 학생 상세 — 기본 기능 완료, 정보 확장 예정

### 현재 표시

- 학생 이름
- 학습 시작일
- 학습 레벨
- 강사 메모

### 현재 연결

- 제목 오른쪽의 수업 목록 링크
- 학생 정보 수정
- 학생 삭제
- 학생 목록으로 돌아가기

### 준비 중 영역

- 다음 예정 수업
- 다음 확인 사항
- 학습 관찰 이력

위 영역은 준비 중 안내 상자로 표시하며 실제 데이터는 아직 연결하지 않았다.

수업별 준비 정보와 분류별 누적 관찰 기록은 현재 수업 준비 화면에서 제공한다.
학생 상세의 확장은 해당 화면과 역할이 중복되지 않도록 검토한다.

## 7. 학생 정보 수정 — 구현 완료

- 기존 학생 정보를 입력 칸에 표시
- 이름, 학습 시작일, 학습 레벨, 강사 메모 수정 가능
- 성공: 학생 상세로 이동
- 입력 오류: 같은 화면에 오류와 입력값 표시

## 8. 학생 삭제 — 기본 기능 완료, 보완 예정

- 학생 상세에서 확인창을 거쳐 POST 요청으로 삭제
- 성공: 학생 목록으로 이동
- 다른 강사의 학생은 삭제할 수 없음
- 연결된 수업이 있는 학생은 DB 외래 키 제약조건으로 삭제가 거절됨
- 해당 상황에 대한 사용자용 오류 안내는 아직 미구현
- 하위 데이터가 자동 삭제되는 기능은 없음
- 연결된 수업이 있는 학생의 삭제 정책과 안내는 후속 작업으로 진행

## 9. 학생별 수업 목록 — 구현 완료, 월별 조회 검토 예정

### 표시

- 학생 이름
- 수업 일시
- 출결 상태
- 상태 메모
- 작업 링크

### 연결

- 제목 오른쪽의 수업 등록 링크
- 수업 일시 변경
- 출결·일보 입력
- 일보가 있으면 일보 상세
- 일보가 없고 출석·지각 상태이면 일보 작성
- 일보가 없고 출석·지각 이외의 상태이면 작성 조건 안내
- 학생 상세로 돌아가기

### 정렬

- 수업 일시 오름차순
- 같은 일시면 수업 ID 오름차순

### 향후 검토

- 연도·월별 수업 조회
- 홈 일정과 학생별 이력 조회의 역할 구분

## 10. 수업 등록 — 구현 완료

- 학생 이름 표시
- 수업 날짜와 시간 필수 입력
- 분 단위 입력
- 등록 시 상태는 SCHEDULED
- 성공: 해당 학생의 수업 목록으로 이동
- 입력 오류: 같은 화면에 오류와 입력값 표시

## 11. 수업 일시 수정 — 구현 완료

- 학생 이름과 기존 수업 일시 표시
- 변경할 수업 날짜와 시간 필수 입력
- 성공: 해당 학생의 수업 목록으로 이동
- 입력 오류: 같은 화면에 오류와 입력값 표시

## 12. 출결·수업일보 통합 입력 — 구현 완료

### 표시

- 학생 이름
- 수업 일시
- 기존 출결 상태
- 상태 메모
- 기존 일보와 관찰 기록이 있으면 해당 입력값

### 상태별 입력 영역

| 상태 | 상태 메모 | 수업 내용·다음 확인 사항·관찰 기록 |
|---|---|---|
| 예정 | 표시하지 않음 | 표시하지 않음 |
| 출석 | 표시하지 않음 | 표시 |
| 지각 | 선택 입력 | 표시 |
| 결석 | 선택 입력 | 표시하지 않음 |
| 취소 | 선택 입력 | 표시하지 않음 |

### 입력 규칙

- 상태는 필수 선택이다.
- 상태 메모는 최대 1000자다.
- 출석·지각은 수업 내용을 필수로 입력한다.
- 일보와 관찰 항목의 입력 제한은 일보 작성 화면과 동일하다.
- 상태 선택을 바꿔 입력 영역을 숨겨도 저장 전까지 입력값을 유지한다.
- 입력 오류 시 숨겨진 영역을 포함하여 제출된 입력값을 유지한다.
- 예정·출석 저장 시 상태 메모는 저장하지 않으며 기존 메모도 제거한다.
- 지각·결석·취소는 상태 메모를 저장할 수 있다.
- 최종 상태가 예정·결석·취소이면 입력 중인 일보 내용은 저장하지 않는다.
- 이미 저장된 일보를 자동 삭제하는 기능은 없다.

### 저장 규칙

- 출석·지각은 출결과 일보·관찰 기록을 함께 저장한다.
- 기존 일보가 없으면 새로 등록하고, 있으면 수정한다.
- 저장 과정에서 오류가 발생하면 출결과 기록의 변경을 함께 롤백한다.
- 성공: 해당 수업의 준비 화면으로 이동
- 입력 오류: 같은 입력 화면에 오류와 입력값 표시
- 관찰 항목을 모두 제거하면 일보는 유지하고 관찰 기록만 삭제한다.

### 상태 변경 제한

- 일본 시간 기준 수업 시작 전에는 출석·지각·결석으로 변경할 수 없다.
- 일보가 있는 수업은 출석·지각 사이에서만 상태를 변경할 수 있다.
- 일보가 있는 수업을 예정·결석·취소로 바꾸려 하면 거절한다.
- 거절 시 기존 DB 값은 유지한다.

### 출결 표시 색상

- 예정: 회색
- 출석: 초록색
- 지각: 주황색
- 결석·취소: 빨간색 계열

## 13. 수업일보 작성 — 구현 완료

### 진입

- 홈, 수업 목록, 수업 준비 화면의 작성 링크로 이동
- 로그인한 강사의 출석·지각 수업에 작성 가능
- 이미 일보가 있으면 기존 일보 상세로 이동

### 입력

- 수업 내용: 필수, 최대 2000자
- 다음 확인 사항: 선택, 최대 1000자
- 학습 관찰 항목: 0개 이상

관찰 항목 한 개의 입력:

- 분류: 필수
- 항목: 필수, 최대 100자
- 관찰 내용: 필수, 최대 1000자

### 관찰 분류

| 분류 | 저장값 | 화면 표시 |
|---|---|---|
| 문법 | GRAMMAR | 文法 |
| 표현 | EXPRESSION | 表現 |
| 발음 | PRONUNCIATION | 発音 |
| 회화 | SPEAKING | 会話 |
| 듣기 | LISTENING | 聞き取り |
| 기타 | OTHER | その他 |

### 조작·저장

- 관찰 항목은 처음에 0개로 시작한다.
- 필요할 때 관찰 항목을 추가한다.
- 추가한 항목은 분류·항목·내용을 모두 입력해야 한다.
- 작성하지 않을 항목은 제거한 뒤 저장한다.
- 저장 버튼 한 번으로 일보와 관찰 항목을 함께 저장한다.
- 성공: 작성한 일보 상세로 이동
- 입력 오류: 전체 저장을 취소하고 같은 화면에 오류와 입력값 유지
- 일보 중복 등록을 방지한다.

## 14. 수업일보 상세 — 구현 완료

### 표시

- 학생 이름과 수업 일시
- 수업 내용
- 관찰 항목 목록
- 다음 확인 사항
- 최초 작성 시각과 마지막 수정 시각

### 배치

- 수업 내용, 관찰 기록, 다음 확인 사항을 각각 상자로 표시한다.
- 작성·수정 시각은 상자 아래 오른쪽에 작게 표시한다.

### 연결

- 일보 수정
- 해당 학생의 수업 목록
- 학생 상세

### 빈 항목

- 관찰 기록이 없으면 등록된 기록이 없다고 표시
- 다음 확인 사항이 없으면 없다고 표시

## 15. 수업일보 수정 — 구현 완료

- 기존 일보와 관찰 항목을 입력 칸에 표시
- 수업 내용과 다음 확인 사항 수정
- 관찰 항목 추가·분류 변경·내용 변경·삭제
- 작성 화면과 같은 입력 규칙 적용
- 저장 버튼 한 번으로 전체 변경 반영
- 일부 처리에 실패하면 전체 변경 롤백
- 성공: 일보 상세로 이동
- 입력 오류: 수정 화면에 오류와 입력값 유지
- 최초 작성 시각은 유지하고 수정 시각 갱신
- 다른 일보에 속한 관찰 ID로 변경할 수 없도록 서버에서 확인
- 관찰 기록만 별도로 작성하는 화면은 제공하지 않음

## 16. 수업 준비 — 구현 완료

### 이번 수업

- 학생 이름과 학생 상세 링크
- 수업 일시
- 출결 상태
- 상태 메모가 있으면 표시
- 출결·일보 입력 링크
- 수업 일시 변경 링크
- 출석·지각 상태이면 현재 수업의 일보 작성·표시 링크

### 직전 수업일보

- 선택한 수업보다 일시가 앞선 같은 학생의 수업을 조회한다.
- 출석·지각 상태 중 가장 최근 수업을 선택한다.
- 같은 일시라면 수업 ID가 큰 것을 먼저 선택한다.
- 이전 출석·지각 수업이 없으면 안내를 표시한다.
- 직전 수업 일시를 표시한다.
- 직전 수업의 일보가 있으면 수업 내용과 다음 확인 사항을 표시한다.
- 다음 확인 사항은 현재 수업에서 확인할 내용으로 보여준다.
- 직전 수업의 일보가 없으면 미작성 안내와 작성 링크를 표시한다.
- 직전 일보가 없다고 더 오래된 일보로 대체하지 않는다.
- 직전 일보 상세로 이동하는 링크를 제공한다.

### 누적 관찰 기록

- 선택한 수업보다 일시가 앞선 같은 학생의 관찰 기록을 조회한다.
- 직전 수업의 일보 유무와 관계없이 누적 기록을 표시한다.
- 문법·표현·발음·회화·듣기·기타 순서로 분류한다.
- 기록이 있는 분류만 카드로 표시한다.
- 분류 이름 옆에 건수를 작게 표시한다.
- 넓은 화면은 3열, 중간 화면은 2열, 휴대폰은 1열로 배치한다.
- 각 분류 안에서는 수업 일시 최신순으로 표시한다.
- 같은 수업 일시면 수업 ID 내림차순, 같은 수업 안에서는 관찰 ID 오름차순이다.
- 최근 기록 3건의 날짜와 항목을 먼저 표시한다.
- 4번째 이후 기록은 펼쳐서 확인한다.
- 각 항목을 누르면 관찰 내용과 원래 일보 링크를 펼친다.
- 기록 전체가 없을 때만 관찰 기록이 없다는 안내를 표시한다.
- 분류 변경 후 다시 조회하면 해당 카드와 건수에 반영한다.
- 일보에 저장된 데이터를 조회하며 준비 화면용으로 복사 저장하지 않는다.

## 17. 오류 및 접근 제한

- 학생이 없거나 다른 강사의 학생이면 404 안내
- 수업이 없거나 다른 강사의 수업이면 404 안내
- 일보가 없거나 접근할 수 없으면 404 안내
- 로그인하지 않은 사용자의 보호된 화면 접근은 로그인 화면으로 이동
- 입력 오류는 해당 입력 화면에서 안내
- 출석·지각 이외의 수업에서 일보 작성을 시도하면 작성 조건 안내
- 중복 일보 작성 요청은 기존 일보 상세로 안내
- 일보가 있는 수업의 상태 변경 제한 안내
- 달력·날짜별 수업 조회도 로그인한 강사를 기준으로 조회
- 오류 안내에 다른 강사의 학생·수업 정보를 노출하지 않음
- 링크를 숨기는 것만으로 권한 처리를 끝내지 않음
- 조회·저장 요청 모두 서버에서 소유 강사를 확인
- POST 요청의 CSRF 보호 유지

## 18. 후속 개발·검토 사항

- 학생별 수업 목록의 연도·월별 조회
- 학생 상세의 준비 중 영역에 실제 정보 연결
- 출결만 먼저 저장하고 홈의 미작성 목록에서 나중에 일보를 작성하는 흐름
- 홈에서 예정 수업만 표시할지에 대한 최종 사용성 검토
- 해결된 관찰 기록의 삭제 또는 해결됨 처리 방식
- 관찰 기록 전체 삭제와 개별 삭제의 구분
- 일보 삭제와 출결 정정 정책
- 연결된 수업이 있는 학생의 삭제 정책과 오류 안내
- 추가적인 화면 디자인과 조작성 개선

출결과 일보의 저장 방식 변경은 현재 즉시 적용하지 않는다.
전체 흐름을 사용해본 뒤 필요성을 판단한다.
