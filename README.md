# ClassBridge

個人の語学講師向けに、学生情報と授業記録を管理するWebアプリケーションです。

現在は、講師アカウントの登録・ログインと学生管理機能を公開しています。
授業スケジュール・出欠・授業記録の管理機能は順次開発しています。

## 公開URL

https://classbridgekr.com

新規登録後、ログインして学生管理機能を利用できます。
動作確認には架空の学生情報を使用してください。

## 実装済みの機能

- 講師アカウントの新規登録
- メールアドレスの重複登録チェック
- BCryptによるパスワードのハッシュ化
- ログイン・ログアウト
- セッションによるログイン状態の管理
- 学生の登録・一覧表示・詳細表示・編集・削除
- 学生名・学習レベル・講師メモの入力チェック
- ログインした講師自身の学生だけにアクセスできる制御
- 存在しない学生やアクセスできない学生に対する404画面

## デプロイ構成

ブラウザ
→ https://classbridgekr.com
→ Render上のDockerコンテナ（Spring Boot）
→ Oracle Cloudのデータベース

- GitHubのソースコードをDockerfileに従ってビルドします。
- ビルドしたアプリケーションをRenderで実行します。
- データベースのパスワードは環境変数で設定します。
- Oracle WalletはRenderのSecret Fileで渡し、起動時に復元します。
- パスワードとWalletはGitリポジトリに含めません。
- ローカル開発用DBと公開環境のDBを分けています。
