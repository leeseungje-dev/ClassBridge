# ClassBridge

個人の語学講師向けに、学生情報と授業記録を管理するWebアプリケーションです。

現在は、講師アカウントの登録・ログイン、学生管理、授業スケジュール・出欠管理、授業記録と学習観察記録の作成・表示・編集機能を実装しています。
学生ごとの観察履歴の一覧表示や、次回授業の準備を支援する機能は順次開発しています。

## 公開URL

https://classbridgekr.com

新規登録後、ログインして学生管理機能を利用できます。
動作確認には架空の学生情報を使用してください。

## 実装済みの機能

- 講師アカウントの新規登録
- メールアドレスの重複登録チェック
- BCryptによるパスワードのハッシュ化
- ログイン・ログアウト
- セッションによるログイン状態の管理
- 学生の登録・一覧表示・詳細表示・編集・削除
- 学生名・学習レベル・講師メモの入力チェック
- ログインした講師自身の学生だけにアクセスできる制御
- 存在しない学生やアクセスできない学生に対する404画面
- 学生ごとの授業登録・一覧表示
- 授業日時順の一覧表示と日時変更
- 予定・出席・欠席・キャンセルの状態管理
- 状態メモの登録・変更・削除
- 授業情報への講師別アクセス制御
- 存在しない授業やアクセスできない授業に対する404画面
- 出席した授業の授業記録の作成・詳細表示・編集
- 授業内容・次回の確認事項・学習観察記録の一括保存
- 学習観察項目の追加・変更・削除
- 文法・表現・発音・会話・聞き取り・その他による観察記録の分類
- 授業記録の重複登録防止
- 授業記録と観察記録への講師別アクセス制御
- 授業記録がある授業の出席以外への状態変更を制限
- 授業一覧での記録作成・閲覧リンクの切り替え

## デプロイ構成

ブラウザ
→ https://classbridgekr.com
→ Render上のDockerコンテナ（Spring Boot）
→ Oracle Cloudのデータベース

- GitHubのソースコードをDockerfileに従ってビルドします。
- ビルドしたアプリケーションをRenderで実行します。
- データベースのパスワードは環境変数で設定します。
- Oracle WalletはRenderのSecret Fileで渡し、起動時に復元します。
- パスワードとWalletはGitリポジトリに含めません。
- ローカル開発用DBと公開環境のDBを分けています。
