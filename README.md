# ClassBridge

個人の語学講師向けに、学生情報と授業記録を管理するWebアプリケーションです。

ホーム画面で授業予定を確認し、出欠の入力や授業記録の作成へ進めます。授業準備画面では、前回の授業記録と分類別の学習観察履歴を確認できます。

## 公開URL

https://classbridgekr.com

新規登録後、ログインして利用できます。
動作確認には架空の学生情報を使用してください。

## 実装済みの機能

### アカウント・学生管理

- 講師アカウントの新規登録とメールアドレスの重複チェック
- BCryptによるパスワードのハッシュ化
- ログイン・ログアウトとセッション管理
- 独自のログイン画面
- 学生の登録・一覧表示・詳細表示・編集・削除
- 学生名・学習レベル・講師メモの入力チェック

※ 授業が登録されている学生は、現在削除できません。削除方針とエラー案内は今後整備します。

### ホーム・授業カレンダー

- 今日以降で予定授業がある最も近い日の授業一覧
- 月別カレンダーと前月・翌月への移動
- 予定・出席・遅刻の授業がある日へのマーク表示
- 日付選択による、その日の全状態の授業一覧表示
- ページ全体を再読み込みしないカレンダー・授業一覧の更新
- 出席・遅刻した授業のうち、授業記録が未作成のものを一覧表示

### 授業・出欠管理

- 学生ごとの授業登録・一覧表示
- 授業日時順の表示と日時変更
- 予定・出席・遅刻・欠席・キャンセルの状態管理
- 遅刻・欠席・キャンセル時の状態メモ入力
- 授業開始前の出席・遅刻・欠席への変更を制限
- 出欠状態に応じた入力欄の切り替え
- 出席・遅刻の保存時に、授業内容を必須として授業記録も保存
- 出欠・授業記録・学習観察記録をトランザクションで一括保存
- 授業記録がある授業は、出席・遅刻以外への状態変更を制限

### 授業記録・学習観察記録

- 出席・遅刻した授業の記録作成・詳細表示・編集
- 授業内容・次回の確認事項・学習観察記録の保存
- 学習観察項目の追加・変更・削除
- 文法・表現・発音・会話・聞き取り・その他による分類
- 授業記録の重複登録防止
- 入力エラー時の入力内容保持
- 授業一覧での記録作成・閲覧リンクの切り替え

### 授業準備

- 選択した授業と学生の情報表示
- 同じ学生の直前の出席・遅刻授業を取得
- その授業の内容と、保存された次回の確認事項を表示
- 直前の授業記録が未作成の場合は、その旨を表示
- 選択した授業より前の学習観察記録を分類別に表示
- 記録がある分類のみカード表示し、件数を表示
- 各分類の最近3件を表示し、残りは展開して確認
- 観察項目をクリックして内容を展開
- 観察記録から元の授業記録への移動

### アクセス制御・画面

- ログインした講師自身の学生・授業・記録だけにアクセスできる制御
- 存在しない、またはアクセスできないデータに対する404画面
- 共通CSSと画面別CSSによるスタイル管理
- ホームへ移動できる固定ヘッダー
- 画面幅に応じたカード配置と表の横スクロール

## デプロイ構成

ブラウザ
→ https://classbridgekr.com
→ Render上のDockerコンテナ（Spring Boot）
→ Oracle Cloudのデータベース

- GitHubのソースコードをDockerfileに従ってビルドします。
- ビルドしたアプリケーションをRenderで実行します。
- データベースのパスワードは環境変数で設定します。
- Oracle WalletはRenderのSecret Fileで渡し、起動時に復元します。
- パスワードとWalletはGitリポジトリに含めません。
- ローカル開発用DBと公開環境のDBを分けています。
- DB変更用のSQLを `docs/sql/` に保存しています。
